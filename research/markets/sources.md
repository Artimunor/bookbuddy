# Market research source inventory

**Archived 21 November 2026.** This inventory contains 357 distinct public URL records from 82 searches and 61 direct web-read calls, including search citations, redirect endpoints and links retained by the ranked study. Tracking-only `utm_*` parameters are normalised in the main record; exact observed variants are retained below each record. Separate language, query, timestamp and mirror URLs remain separate records. A URL record is not a count of unique publications.

**Evidence status:** search-only snippets and generated search summaries are discovery material, not independent verification. A successful HTTP response can still be an unpublished article, a security challenge, an incomplete legal-page shell or an unparsed binary. Failed fetches were not silently replaced with invented data. No new external request was made to build this archive.

**Use status:** “Used” means the URL is cited in `markets.md`; it does not certify every sentence in its archived extract. Unused contextual, conflicting, obsolete and unrelated results are preserved rather than promoted as findings. Public source URLs are retained; contact details, machine paths and access tokens are not.
