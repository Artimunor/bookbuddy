# Visual review: 106 mobile artboards

**21 findings: 1 blocker, 7 major, 13 minor.** The blocker is the invitation handoff: the account shown accepting the invitation is not the account to which the provider sent it. Other fixes affect the Arabic shift window, the approved scope, the cover timeline and the capacity shown before booking. No artboards were changed.

## What was checked

Reviewed revision `beef877672a5d8d1105bfef1ed7f4e477e9aa2b2`, with no working-tree changes under `design/` at the source check. A temporary Bun script checked all 106 screen SVGs; the template was checked separately. All 106 were rendered with Quick Look and inspected, including variants, not just the 70 primary screens. Quick Look’s direct `-t -s 844` thumbnails showed only the top of each portrait artboard. For full-height inspection, the same command rendered temporary square wrappers containing the original unscaled 390 × 844 SVGs. The contact sheets show the 390 × 844 region, including the home indicator. The template and S-10 were reviewed at the same scale. This is evidence about the drawings, not native hit regions, screen-reader behaviour or live server state.
